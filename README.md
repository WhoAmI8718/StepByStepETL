# StepByStepETL

Учебный ETL-проект, создаваемый с нуля без оркестратора.

## Цель

Построить pipeline:

CSV → extract → transform → validate → load → PostgreSQL

## Текущий этап

Настройка структуры Python-проекта, Git и тестового окружения.

## Подготовка окружения

1. Создать виртуальное окружение: `python -m venv .venv`
2. Активировать окружение: `.\.venv\Scripts\Activate.ps1`
3. Установить инструменты разработки: `python -m pip install -r requirements-dev.txt`
